## FluxCreate home versus a complete creative-suite workspace

The home app already launches the studios, shows local recent-document metadata, shares appearance/settings and exposes the authenticated deployment. Missing suite-level capabilities are substantial:

| Area | Missing or partial | Next acceptance condition |
|---|---|---|
| Documents | Suite-wide named documents, searchable recent files, checkpoints and storage usage remain partial. FluxAgents now has a bounded local named/versioned workflow library; other studios do not inherit it | Save/open two named documents per studio without overwriting either; recover prior revisions |
| Assets | Shared libraries, folders/tags, deduplication, missing-media/relink and provenance | One photo reused across apps without multiplying storage; missing assets visibly repairable |
| Accounts | App identities, workspaces, per-project sharing and roles | Users and background jobs have explicit, revocable ownership; deployment auth remains separate |
| Sync | Cross-device project/media sync, offline conflict handling | Restart/offline edits preserve both versions and expose a deliberate merge choice |
| Connections | Account-synced personal credentials and revocable background connections | No key enters project files or transfer records; expiry never falls back silently |
| Integration | Shared source controls now work in Fluxfoto/Fluxiffects/Fluxini/Flux3D; browser inbox/outbox/history, review and duplicate claims persist. Live source sync, shared asset identity and distributed exactly-once insertion remain absent | Expand supported renderers/types while preserving source, stale guards and undo; reconcile interrupted application explicitly |
| Billing | Managed prepaid AI credits and Stripe are planned after gap work; BYOK remains available. ## Music Video Studio preview — 17 October 2026

Fluximiére now has a dedicated music-video workspace: concept and character/scene references, song import (at least one second; longer songs use a 180-second excerpt with a five-second fade-out and preserve their full original), measured onset/tempo candidates, manual BPM/first-beat correction, beat-aligned editorial shots, editable ideas/reference assignments/locks, and an editable still/placeholder animatic with one continuous prepared soundtrack. The workspace keeps at most 128 MiB of local media; song uploads are limited to 64 MiB. Long-song originals remain downloadable; preview, analysis, direction and timeline share the faded excerpt. Metadata-only Markdown recipes can be reopened and original assets relinked by SHA256. IndexedDB saves use revision conflict checks. Native editor v1/v2 remains unchanged; production lineage stays in the separate recipe.

Gemini multimodal direction is implemented behind strict capability checks, with real full-song 8 kHz mono WAV input and bounded reference thumbnails, paged proposals, locks, cancellation, no automatic retries, and analyze_music/get_beat_grid/preview_edit inspection tools. It is mock-tested, not paid-pilot qualified. **Live listening currently blocks before inference:** the public Gateway catalog returned Gemini 4 Argon inputs text/image/PDF/video without audio on 17 October. No silent model or text-only fallback is used. Model/profile upgrades remain explicitly reviewed, not automatic catalog substitutions.

Still open: canonical PCM retention and director FFmpeg/cut-tool execution; multi-section creative timing; frame generation and Pruna takes; approved quotes/spend limits; app ownership/private hosted media; native v3/packages; durable background jobs; take review/assembly and full-song decoded export qualification. Reduced-resolution listening is for direction, not sample-accurate performance alignment. Unapplied direction proposals are temporary; durable resumable passes remain a later milestone. No paid generations were run.

## Important corrections to the previous optimization list

- Photo masks, real image imports, rounded rectangles, core recovery guards, personal Gateway settings, authenticated hosting, video/speech generation and local FluxAgents persistence are already implemented. They must not be counted as entirely missing.
- Fluxfoto drag ordering and bounded layered PSD output are included in this continuation. PSD text/shapes/masks are pixel layers, not native Photoshop text, paths or editable mask controls. A visible canvas eraser requires an appearance layer plus a hidden group of originals.
- Atomic imports are implemented in several editors; the shared Building label means the suite-wide contract still needs work. It is not proof that every editor is unsafe.
- FluxDesign PDF import cancellation exists; PDF export cancellation and IDML parsing in a cancellable worker remain missing.
- Fluxiffects recovery has been verified; an older app note marking it Next is stale.
- Fluximiére now exports synchronized stereo sound with timestamped WebCodecs video; real-time capture is a separate compatibility choice. Fluxiffects now adds a separate bounded timestamped WebCodecs exporter with stereo audio and keeps its explicit real-time compatibility mode. See [Fluximiére audio](../../Fluximiere/docs/AUDIO-ENGINE.md) and [Fluxiffects audio](../../Fluxiffects/docs/AUDIO-EXPORT.md).
- Browser IndexedDB persistence is not cloud sync. Vercel authentication is not application accounts. Local background recovery is not hosted durable execution.
- Source objects now have real rendering/review/placement/replacement/refresh controls in the four requested editors. They remain rendered snapshots with recoverable source, not live-linked native objects. Fluxini source import uses Flux Exchange rather than arbitrary native procedural graph rendering.
- The four-editor floating helper now uses the official MCP client/server and existing validated planners. Reference editing is restricted by documented integration plus live image-input capability; paid provider output was not tested and AI upscale remains unavailable.
- Browser transfer storage retains bounded pending work and receipts across reload, with cross-tab claim protection. It is origin-local storage, not a distributed exactly-once protocol or cloud artifact store.
- Fluxfoto’s rectangle, ellipse and lasso selections now support invert/feather and undoable masks with stale/cancel guards; combined selection algebra, internal isolated-layer clipboard, separate fill, mask-based cut/hide and atomic multiple-layer editing are locally verified in the parallel continuation. Retouching, groups and advanced selection refinement remain open.

Follow the [integration review](INTEGRATION-REVIEW.md) and [detailed implementation plan](IMPLEMENTATION-PLAN.md) for the next work. The historical [optimization audit](OPTIMIZATIONS.md) remains the record of previous deliveries.

## Director image strategies — 17 October 2026

Each director proposal now chooses reference images, a start frame, or start-and-end frames for every unlocked shot, with a reason, frame prompts and a scene-continuity approach. Decisions use duration, movement, identity and transitions; duration alone does not require an end frame. Continuous-scene intent describes longer actions that could later supply several short editorial cuts, without changing the beat-aligned timing or claiming a shared generated take already exists.

Choices can be reviewed before applying, edited in each storyboard card, saved, locked and exported in the recipe. Older shots remain explicitly unplanned until a decision is made. Visual-plan changes invalidate dependent takes. This is planning only: image/video generation, supported-provider input checks, duration checks and approved-cost execution remain open. Gemini audio capability remains blocked as documented in the preview release; tests use mocked proposals and incur no generation charges. See [verification](RELEASE-VISUAL-PLANNING-2026-10-17.md).


## Music-led shot pacing — 17 October 2026

New storyboards default to Follow the music. Bounded one-second relative energy and rhythmic-activity measurements guide local shot length; nearby measured change cues favor cuts on available beats. Energetic/cinematic controls bias the feel instead of imposing a repeated duration. Uniform music may produce repeated lengths; no random variation is added. Older maps fall back to local beat density and show a prompt to reanalyze for energy data. Manual beat corrections retain measured dynamics. Locked/reviewed shots cannot be overwritten by rebuilding.

This remains deterministic audio-feature timing, not semantic verse/chorus or lyric understanding. Final holds can be longer to avoid short leftover flashes; pacing-window diagnostics remain available. Numeric timing calls remain compatible for older callers/tests, but the studio UI uses adaptive modes. See [verification](RELEASE-MUSIC-PACING-2026-10-17.md).
