# Verified feature-gap milestone — 2026-10-09

This release advances all eight studios and the shared workspace. It does not complete the full product-parity roadmap. [Remaining gaps](FEATURE-GAPS.md), [implementation progress](IMPLEMENTATION-PROGRESS.md), and [next milestones](IMPLEMENTATION-PLAN.md) stay explicit.

## Delivered scope

- Fluxfoto: rectangular, elliptical and freehand selections; invert/feather; reversible selection masks with cancellation and source-pixel preservation.
- FluxDesign: searchable compatible text, vector shapes, image embedding/conversion and a downloadable PDF compatibility report. Unsupported fonts/glyphs retain an image page; an all-image proof is also available. Reviewed ICC-image conversions preserve browser colors.
- Fluximiére: bounded PCM playback, scrub/reverse, real waveforms and stereo mixing; timestamped WebCodecs WebM audio/video export and a separate real-time compatibility path.
- Fluxiffects: stereo audio with animated gain/fades in bounded real-time WebM export, including native 3D scenes.
- Fluxini: shared header and themes, consistent controls and a readable resizable graph dock; existing scene/history behavior preserved.
- Flux3D: visible source objects with native recovery and embedded preview materials in GLB.
- FluxLab: official HTTP MCP transport, context-aware editor helper, per-request connections and bounded reference-image editing. Fluxfoto/Fluxiffects/Fluxini support reviewed generated insertion; Flux3D supports editable proposals and explanation.
- FluxAgents: text/boolean condition steps, guarded branches, ordered joins and persisted decisions/skips with local recovery.
- Shared: supported destination registry, recoverable source placement/replacement/refresh in four editors, browser inbox/outbox/history and duplicate application guards.

## Automated verification

All 454 source tests passed: Fluxini 97, FluxExchange 17, FluxCreate 48, Fluxfoto 25, FluxDesign 22, Fluximiére 33, Flux3D 38, Fluxiffects 93, FluxLab 59, FluxAgents 22.

All nine browser builds, the MCP App resource and bundled hosted API built successfully. The release lockfile passed frozen validation. The existing dependency directory was preserved when Windows blocked its replacement; local missing links were repaired, while the committed lockfile describes the clean deployment install.

The hosted browser suite passed 36 checks covering all eight studio URLs, home navigation, recents, worker/bridge assets, editable text and image insertion into four editors, persistence, invalid-image failure and absence of runtime errors/missing resources. Six packaged-API checks verified real official-SDK discovery and the bundled MCP resource across five endpoints, plus cross-origin rejection.

Focused checks additionally cover:

- Actual selection-mask pixels, rotation/feather, undo/reload, and delayed image-decoding cancellation with Escape and Ctrl+D.
- Original-source recovery, visible preview pixels, transforms, replacement/refresh, undo, native persistence, GLB material decoding and stale/cancel guards.
- Receiver reload without an opener, second-tab application claims, terminal receipts and ambiguous interrupted-insertion recovery.
- Real MCP protocol with mocked providers; personal credential isolation, stale context, proposal review, insertion, cancellation and no implicit paid retries.
- Independently decoded stereo export tones/impulses and source timing. A ten-minute low-resolution Fluximiére fixture showed no accumulated audio drift; this is not a full-resolution performance benchmark.
- Independent PDF text extraction and pixel rendering, source equality, font/glyph fallback, image profiles, report/proof behavior and six PDF browser groups.
- Fluxini themes at 1600, 1280 and the 1000×720 supported minimum; graph resize/focus/fullscreen restoration and unchanged scene revisions.
- FluxAgents version-1 compatibility, conditions, skipped branches, joins, budgets, approvals, cancellation, retries and restart recovery. An independent runtime review found no actionable issues.

No paid model generation was performed. Hosted live autonomous workflows remain disabled. Browser storage is not cloud sync; embedded source snapshots are not live linked documents; process-local MCP duplicate protection is not a durable cross-instance job ledger. PDF font embedding/print compliance/export cancellation, professional retouching/RAW, advanced animation/mesh tools and other detailed gaps remain open.
