# Custom easing curves

In **Animate**, choose **Custom curve** on a keyframe. Its curve controls the segment from that keyframe to the next. Drag either handle, enter its time/value coordinates, or focus a handle and use arrow keys (Shift moves by 0.1). Pointer movement previews the curve locally; release applies one Undo step. Escape or pointer cancellation discards the gesture. Locked layers disable the controls.

The stored form is `easing: "cubic-bezier"` with `bezier: [x1, y1, x2, y2]`. All four coordinates are finite numbers from 0 to 1. This deliberately bounded editor does not provide overshoot, spatial motion paths, a velocity graph or linked tangents. Numeric properties, color interpolation, volume automation, preview and output use the same time-inverted cubic evaluator. Existing five easing presets retain their behavior. Updating an existing key's value preserves its easing and controls.

Native save, autosave/recovery and the native FluxExchange source snapshot preserve the curve exactly. Editable Fluxini conversions approximate custom curves with linear easing; both the Exchange export review and the destination conversion report disclose that limit. Explicitly restoring the original Fluxiffects snapshot restores the exact controls. Fluxfoto and FluxDesign sample the first frame through the custom evaluator and report the still-frame conversion. Fluximiére reports that animation is simplified. Keep the native source or render the motion for matching output. The AI command schema remains limited to the existing preset easings.

Verification: 96 unit tests and 14 existing browser workflows pass. The custom browser fixture verifies entered control points, successful and cancelled pointer gestures, keyboard edits, single-step Undo/Redo, reload and unchanged audio source bytes. A quadratic reference curve puts the exported rectangle at pixels 90–109 at 0.5 seconds, matching its expected center of 100 pixels. The same curve's offline sound RMS is 0.08707 early and 0.13931 midway; independently decoded WebM RMS is 0.08523 and 0.13647. The 1.2-second movie decodes to two sound channels and 1.2 seconds. These checks retain the existing real-time codec/export limits; they do not claim deterministic movie timing.
