# FluxCreate app names

Effective **3 November 2026**.

Use the exact display names below, with capitalized word initials.

| Display name | Previous display name | Internal app ID / hosted route | Source folder |
| --- | --- | --- | --- |
| FluxFoto | Fluxfoto | `fluxoto` / `/fluxoto/` | `Fluxoto/` |
| FluxDesign | FluxDesign | `fluxidesign` / `/fluxidesign/` | `Fluxidesign/` |
| FluxVideo | Fluximiére | `fluximiere` / `/fluximiere/` | `Fluximiere/` |
| FluxMotion | Fluxiffects | `fluxiffects` / `/fluxiffects/` | `Fluxiffects/` |
| FluxEffects | Fluxini | `fluxini` / `/fluxini/` | `Haidini/` |
| Flux3D | Flux3D | `flux3d` / `/flux3d/` | `Flux3D/` |
| FluxLab | FluxLab | `fluxlab` / `/fluxlab/` | `FluxLab/` |
| FluxAgents | FluxAgents | `fluxagents` / `/fluxagents/` | `FluxAgents/` |

FluxMotion is the layer/keyframe compositing editor. FluxEffects is the procedural/node/simulation editor. These are distinct apps.

Use the current names in interface text, titles, accessibility labels, supported-workflow documentation and new announcements. Historical release records can retain the names used at the time.

Native format tags, file extensions, browser databases, environment variables, package IDs, exported function names, source folders and hosted routes retain their existing compatibility identifiers. Older project content and user-created titles are not rewritten. Do not rename those identifiers as a cosmetic change; any future migration needs its own compatibility plan.
