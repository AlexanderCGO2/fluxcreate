# Selection-clipped photo paint plan

Approved bounded continuation: selected-photo paint/erase captures an immutable optional clip per stroke. The recipe contains canonical selection geometry, document frame, document-pixel feather and affine document-to-retained-paint mapping. Rasterize feather in the original document frame before affine mapping; outside that frame remains transparent even when inverted. Later layer transforms carry both paint and clip; changing/deselecting workspace selection cannot alter committed strokes.

Extract app-local selection validation/path/raster functions without changing existing callers. Strict native recipe validation; existing selection limits 32 operations/5000 lasso points plus aggregate32768 retained clip vertices per image. Clip frames <=8192-side/16MP, padded feather stencil <=24MP. One global document-stencil cache (<=16MP), released before replacement, two reusable clipped-stroke/mask scratch surfaces under existing renderer32MP limit, released after layer drawing. Legacy unclipped drawing path byte-identical. No hardness, shared contracts or dependencies.

Capture selection+feather at pointer down; changing either midgesture cancels. Preserve isolated preview/history/autosave/export invariants. Verify combined/inverted/feathered geometry, transforms, lower layers, source bytes, mask/Levels/Curves order, native/PNG/PSD/portable/studio once, immutable replay after selection changes, cancel/undo/stale isolation, budget rejection and AI redaction. RED first, then full units/build and affected browser regressions. Main-thread stencil performance remains bounded but unprofiled.
