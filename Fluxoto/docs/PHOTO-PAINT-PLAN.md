Original src and suite source remain intact. Rendering isolates the image, applies local paint/erase before Levels/Curves/mask/appearance, and uses the same result in PNG/PSD/portable/studio snapshots. Portable baking clears paint once. Empty/absent paint does not add a raster pass.

Explicit Brush target: Separate stroke layer (legacy composite stroke behavior) or Selected photo.
